# Architecture Decisions

- Architecture is a user decision. Analyze alternatives, constraints, trade-offs, migration cost, and operational impact before recommending a direction.
- Never change an existing architecture, service boundary, communication style, or deployment topology without explicit user approval.
- Recommendations must be justified by current requirements rather than fashion or generic best-practice slogans.
