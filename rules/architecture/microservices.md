# Microservices

- Do not introduce or remove microservices without explicit user approval.
- Recommend microservices only when concrete boundaries, independent scaling/deployment, failure isolation, ownership, or workload separation justify the operational cost.
- A monolith or modular monolith is not considered inferior by default.
