# Scope Discipline

- Change only what is necessary for the requested outcome.
- Do not redesign neighboring modules, rename unrelated symbols, reformat unrelated files, or upgrade unrelated dependencies.
- Prefer root-cause fixes over suppressing symptoms.
- New abstractions require a current concrete need; do not build speculative framework layers.
