# CI/CD

- Automate repeatable lint, type, security, test, build, and deployment checks appropriate to the repository.
- CI configuration changes must preserve existing release/deployment ownership and never deploy without the user's authorized workflow.
- Fail clearly rather than silently skipping critical checks.
